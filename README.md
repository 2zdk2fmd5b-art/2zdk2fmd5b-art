# 윤영서

**유원대학교 미디어콘텐츠학과 · AI 영상과 미디어아트**

안녕하세요. 이미지와 영상으로 분위기와 이야기를 표현하는 데 관심이 있는 윤영서입니다.
AI로 만든 이미지에 움직임과 음악을 더하고, 하나의 영상으로 편집하는 작업을 하고 있습니다.
색감과 장면의 흐름, 소리가 어우러지는 방식을 고민하며 AI와 실감미디어를 활용한 표현을 배우고 싶습니다.

## 관심 분야

- **AI 기반 영상 제작**: 이미지에 움직임을 더해 장면의 분위기를 표현하는 작업
- **미디어아트와 실감미디어**: 영상과 소리를 통해 관람객이 감상할 수 있는 경험을 만드는 작업
- **영상 편집과 음악**: 장면의 흐름과 음악을 연결해 작품의 감정을 전달하는 작업

## 도구 활용 경험

| 도구 | 활용 경험 |

## 대표 프로젝트

### 화색연가

**AI 영상 · 개인 제작 · 단체전 출품**

〈화색연가〉는 한국화풍의 자연 이미지에 움직임과 동양풍 음악을 더한 영상 작품입니다.
꽃과 나비, 수면 등의 장면을 연결해 색과 계절의 분위기가 이어지도록 구성했습니다.
정적인 자연 이미지를 영상과 음악으로 확장해 감상할 수 있는 작품으로 만드는 것이 목적이었습니다.

#### 작품 영상

[〈화색연가〉 원본 영상 다운로드 · MP4, 약 131MB](https://github.com/2zdk2fmd5b-art/2zdk2fmd5b-art/releases/download/hwasaekyeonga-v1/hwasaekyeonga.mp4)

원본 파일을 내려받은 뒤 기기의 동영상 플레이어로 감상해 주세요. 위 링크는 다운로드용이며, 링크를 열자마자 웹에서 재생되는 스트리밍 주소는 아닙니다. 기기와 브라우저에 따라 파일을 여는 방식이 다를 수 있습니다.

직접 다운로드가 어려우면 [작품 영상 Release 페이지](https://github.com/2zdk2fmd5b-art/2zdk2fmd5b-art/releases/tag/hwasaekyeonga-v1)를 열고 **Assets → hwasaekyeonga.mp4**를 선택해 주세요. **Source code (zip/tar.gz)**는 작품 영상이 아닙니다.

#### 내가 맡은 역할

이미지와 영상 생성, 음악 제작, 영상 편집을 진행했습니다.
Midjourney, Kling, Suno를 활용해 시각·청각 요소를 만들고, Adobe 영상 편집 도구로 장면과 음악을 연결했습니다.

#### 제작 과정

1. **이미지 제작**: Midjourney로 한국화풍의 자연 이미지를 제작했습니다.
2. **영상 제작**: Kling을 활용해 이미지에 움직임을 더했습니다.
3. **음악 제작**: Suno로 영상에 사용할 동양풍 음악을 제작했습니다.
4. **편집**: 생성한 영상과 음악을 연결해 하나의 작품으로 구성했습니다.

#### 제작 결과

개인 영상 작품 〈화색연가〉를 완성하고, 〈Blooming Nature〉 단체전에 출품했습니다.
작품 제작은 개인 작업으로 진행했으며, 전시는 다른 참여자들과 함께한 단체전입니다.

## 앞으로의 목표

AI와 실감미디어를 활용해 영상과 소리가 어우러지는 작품을 이어서 만들고 싶습니다.
영상 편집과 장면 전환을 더 배우고, 표현하려는 분위기에 맞게 이미지와 음악을 구성하는 능력을 발전시키려 합니다.
앞으로는 작품의 콘셉트와 제작·수정 과정도 함께 기록해 나가겠습니다.
